# MailDock Privacy Policy

_Last updated: November 6, 2026_

MailDock is a personal email app for macOS. It runs only on the owner's own Mac and is not offered to the public.

**What it accesses.** MailDock uses the Gmail API (scope `gmail.modify`) solely to display, search, organize and send the signed-in user's own email.

**Where data goes.** Email travels only between the user's Mac and Google's servers. There is no MailDock server. Nothing is collected, sold, shared with third parties, or used for advertising or analytics.

**What is stored.** Sign-in tokens are kept in the macOS Keychain. A short list of recent message summaries is saved in the user's Application Support folder so lists open quickly. Removing an account in MailDock deletes its saved data and revokes its access.

**Revoking access.** Access can be removed at any time from the account's Google settings at https://myaccount.google.com/permissions.

**Google API Services.** MailDock's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Contact.** Questions can be raised as an issue on this repository.
